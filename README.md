# Chetana Reddy Sunkugari — Portfolio

Personal portfolio site, built with React, TypeScript, and Vite.

## Content

Experience and project entries are tagged by focus area (Supply Chain & Ops,
Business Operations, Strategy & Ops) in `src/data.ts`. The filter buttons on
the Experience and Projects sections use these tags to highlight the bullets
relevant to whichever track a visitor cares about.

## Development

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```

## Deploy

The `dist/` folder from `npm run build` can be hosted on any static host
(GitHub Pages, Vercel, Netlify, etc.).
